# pygame
jogo pygame para feira de design de software

Turma C

Nome do jogo: 1, 2, 3, VIROU!

Integrantes do grupo: Ana Luiza Alves, Mariane Cristina Carvalho, Rafaela Assis

o projeto está disponível no repositório do GitHub. Após clonar o repositório, basta abrir a pasta do projeto e executar os seguintes comandos no terminal:

pip install pygame-ce

python jogo.py

A pasta imagens já está incluída no repositório, portanto a tela inicial e os demais elementos visuais são carregados automaticamente ao rodar o jogo.
